# ۲۰۴۸ (2048)

یک نسخه ساده و وب‌محور از بازی پازل ۲۰۴۸ با رابط کاربری فارسی (راست‌به‌چپ)، نوشته‌شده با HTML، CSS و جاوااسکریپت خالص — بدون هیچ وابستگی یا فریم‌ورکی.

## اجرای بازی

فقط فایل `index.html` را در مرورگر باز کنید، یا یک سرور استاتیک محلی اجرا کنید:

```bash
npx serve .
```

## نحوه بازی

- با کلیدهای جهت‌دار (↑ ↓ ← →) یا با کشیدن انگشت روی صفحه‌های لمسی، بلوک‌ها را حرکت دهید.
- بلوک‌های هم‌مقدار که به هم برخورد کنند، یکی می‌شوند و مقدارشان دو برابر می‌شود.
- هدف رسیدن به بلوک ۲۰۴۸ است؛ اگر هیچ حرکتی ممکن نباشد، بازی پایان می‌یابد.
- دکمه «بازی جدید» بازی را از نو شروع می‌کند و بهترین امتیاز در `localStorage` مرورگر ذخیره می‌شود.

## ساختار فایل‌ها

- `index.html` — ساختار صفحه
- `style.css` — استایل‌دهی و تم روشن/تاریک خودکار
- `script.js` — منطق بازی (شبکه، حرکت‌ها، ادغام بلوک‌ها، امتیاز)
